# Narrator voice folder

Phase 1 defines this folder without changing current game playback.

Future narrator recordings use these basenames:

```text
find-intro
find-again
find-correct
find-complete
memory-start
memory-match
memory-no-match
memory-complete
```

Find phrases that include a person can be assembled from a narrator prompt followed by a reusable name clip under `names/`.

Supported audio extensions are `.mp3`, `.webm`, `.mp4`, `.ogg`, `.wav`, and `.m4a`.
