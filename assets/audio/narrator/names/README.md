# Narrator name clips

Save one spoken name per character using the character key:

```text
grandad.webm
granny.webm
joshua.webm
kenneth.webm
```

The future Find-game narrator can combine a shared phrase such as `find-intro.webm` with the selected character's name clip. Adding a new character then requires only one new name recording.
