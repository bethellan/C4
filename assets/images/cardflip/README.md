# Card Flipping Game Images

Put alternate card-flip photos in this folder.

Use these filenames:

- grandad.jpg
- granny.jpg
- andrew.jpg
- marilyn.jpg
- joshua.jpg
- isabella.jpg
- jj.jpg
- leon.jpg
- loke.jpg
- malcolm.jpg
- tess.jpg
- sue.jpg
- brian.jpg

Recommended:
- square or near-square images
- JPG or PNG
- clear face / upper body
- not too large; around 800–1200 px wide is plenty

The card flipping game uses an exact filename map generated from this folder. Current files include `.PNG`, so the app must not assume `.jpg` only.

Example path:

assets/images/cardflip/grandad.PNG

If no cardflip image is found, it falls back to the normal character portrait.
